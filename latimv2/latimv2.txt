latim v2 - uma lingua criada no tédio

pronomes:
ehgo = eu
me = me/mim
tus = tu
te = te/ti
mnohs = nós
mnos = nos (objeto)
uohs = vós
uos = vos (objeto)
meh = meu/minha (masculino)
mehr = meu/minha (feminino)
teh = teu/tua (masculino)
tehr = teu/tua (feminino)
nostrum = nosso/nossa (masculino)
nostra = nosso/nossa (feminino) (sim, nao usa mn-)
uostrum = vosso/vossa (masculino)
uostra = vosso/vossa (feminino)

hoc- = isso/esse/essa (hocus, hoca, hoci, hocae...)
ill- = aquele/aquela (illus, illa, illi, illae)


ordem das coisas nessa seção: (nom./obl./gen.)
generos: masculino (-us/-um/-eh) e feminino (-a/-am/-ehr)
plural: masculino (-i/-os/-(e)rum) e feminino (-ae/-as/-(e)ra)


casos:
nominativo = sujeito
obliquo = objeto (direto e indireto)
genitivo = posse


conjugação basica:
-oh = ehgo bepoh aquam (eu bebo água)
-es = tus bepes aquam (tu bebes água)
-et = illus bepet aquam (ele bebe água)
-emuhs = mnohs bepemuhs aquam (nós bebemos água)
-eis = uohs bepeis aquam (vós bebeis água)
-uhnt = illi bepunt aquam (eles bebem água)
-ih = ehgo bepih aquam (eu bebi agua)
-isti = tus bepisti aquam (tu bebeste água)
-ut = illa beput aquam (ela bebeu água)
-imus = mnohs bepimus aquam (nós bebemos água)
-istis = uohs bepistis aquam (vós bebestes água)
-ent = illae bepent aquam (elas beberam água)

casos especiais pro verbo esse (pq ele é especial):
est = é
es = és
soh = sou
semuhs = somos
seis = sois
suhnt = são


notas:
1. verbos só terminam em ehre. Só.
2. h em fim de silaba marca vogal longa. Em inicio representa o som de "h" mesmo (fricativa glotal).
3. consoantes sao geminadas, assim como no latim clássico.
4. preposições vêm do latim clássico.
5 (IMPORTANTE). o sistema de pronomes possessivos aqui trata os pronomes como substantivos "comuns", ou seja,
eles nao concordam com o objeto possuido, concordam COM O POSSUIDOR. Ex. Panus teh e pani teh são válidos.
Estranho seria falares "pani teh" com uma mulher, ou "pani tehr" com um homem.
6. Esse sistema faz adaptações grosseiras nas palavras pra caberem no sistema de casos (forçando terminações). Em poucos casos isso não acontece.

futuro é basicamente "habehre conjugado + verbo no infinitivo/normal"
passivo é expresso com verbo conjugado + -tur
