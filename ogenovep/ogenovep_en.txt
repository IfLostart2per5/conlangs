Ogen-ovep Language
Based on biconsonantal roots and particles

sounds (30):
vowels (12): a, e, i, o, u, ü (sound [y]) + their long versions
consonants (18):
  plosives (6): k, t, p, b, g, d
  fricatives (6): h, s, z, x, v, f
  nasals (2): n, m
  liquids (2): l, r
  approximants (2): j, w
THERE NO DIGRAPHS. so sequences like "sh" are [sh], not [ʃ].
phonotactics: (C)(C)V(V)(C)

molds:
agent: C₁oC₂
concept: oC₁eC₂
instrument: C₁üC₂
organ: C₁üaC₂
active verb (you do this action to someone): C₁eC₂
passive verb (someone do this action to you): C₁eiC₂
participle verb (adjective form that indicates that the object did such an action): C₁aC₂et
profission: C₁iC₂
object: C₁uC₂
place: maC₁aoC₂
adjective: C₁aC₂
intensifier: i + molde
absolute intensifier: u + molde
weakener: a + molde
antonim: molde + as
belief: guC₁oC₂
adverb: C₁eC₂a

the numberw:

how to form numbees:
11-20: mekav (10) + number
20-99: number + mekav (10) ou 1st number + 2nd number
100-999: me (reduced form of memak) + number
1000 a 999999: ime + thousand number + number
millions, trillions etc.: ume + number + other numbers

articles (optional, useful for clarity):
definite: zu (from the first consonant of zn, sensation)
indefinite: vu (from the first consonant of vn, unknowm)

verb endings:
tense:
  -et = past
  -ut = present
  -at = future
aspect:
  -i = not initiated
  -a = initiated
  -u = done
volition:
  -m = desire, volitive
  -p = acident, non-volitive
  -g = obligation
  -x = needing
  -k = ocult (it dont know/it dont want to show)
negation: -ü
imperative: -i

Put these elements in order to conjugate:
normal: tense aspect volition [negation]
infinitive negation: negation only
imperative: volition imperative
[] indicates optionality
nothing indicates obligatority

short forms of the verb "to be" for past and future:
vetuk = foi
vetik = será

the pronouns are:
ma = pronouns base, alone it means "this" for objects
ama = I
uma = you
ema = he/she
nema = she
kema = he
āma = we
ūma = you (plural)
ēma = they
nēma = they (women)
kēma = they (men)

demonstratives:
me = this
be = that

The order is rigidly SOV, but you can use certain particles to change it:
ta = marks the subject (who does)
ku = marks the direct object
han = marks the indirect object
sa = marks the instrument
vo = marks the place
vom = marks the destiny
ni = marks the cause
mu = marks the purpose
so = against
tek = than
ogo = similar to with
ko = marks possession
xo = marks a part of somethimg
extra particles ():
nü = condicional (se)
xe = potencial (poderia ocorrer?)
ke = optativo (tem permissão?)
lu = então

pronomes interrogativos se formam muito com o campo vn (desconhecido):
vun = o quê
von = quem
vena = como
mavaon = onde

conjunções:
wa = ou
ja = e
plural é indicado estendendo a primeira vogal da palavra (usa-se macron)
