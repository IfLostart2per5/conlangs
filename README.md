# conlangs
The conlangs I have created :)

## Example
For phrase "I love apples!", you wold say it:
in Ogen-ovep: Wok muul xetutum (in IPA, /wok muːl xe.tu.tum/. in English, approximatelly: "Wock mool hetutum")
in Gains: Hus kraxotinoîf xotoa (in IPA, /us kra.xo.ti.nɔjf xo.to.a/, in English, approximatelly: "huss krahoteenoyph hotoah")
in Vlacjctaj: (Wo) ûkhten kokc (in IPA, /(wo) ɯx.ten kɔks/, in English: "(Wo) u-hten kocks" (I wrapped 'wo' in parenthesis because it's optional, as the language has personal inflection)
